# 小学英语单词学习系统

一个专为小学生设计的英语单词学习网页应用，覆盖3-6年级全部内容。

## 功能特点

- 📚 **单词学习**：3-6年级上下册全覆盖，共48个单元
- 🔊 **真人发音**：使用Web Speech API提供标准发音
- 💡 **例句展示**：每个单词配有专属例句和中文翻译
- 📖 **课文朗读**：支持课文内容朗读学习
- 📝 **单词测试**：随机测试巩固记忆
- 📱 **响应式设计**：支持电脑、平板、手机访问

## 技术架构

- **类型**：纯前端网页应用
- **技术栈**：HTML5 + CSS3 + JavaScript (ES6+)
- **数据存储**：本地JSON数据
- **音频**：Web Speech API

## 快速开始

### 本地使用

1. 下载所有文件到本地文件夹
2. 双击 `index.html` 用浏览器打开
3. 开始使用！

### 部署上线

#### 方案1：GitHub Pages（免费）

1. 在GitHub创建新仓库
2. 上传所有文件到仓库
3. 进入 Settings → Pages
4. Source 选择 "Deploy from a branch"
5. Branch 选择 "main" / "/ (root)"
6. 保存后等待几分钟，访问 `https://你的用户名.github.io/仓库名`

#### 方案2：Vercel（免费，推荐）

1. 访问 [vercel.com](https://vercel.com)
2. 注册/登录账号（可用GitHub账号）
3. 点击 "Add New Project"
4. 导入GitHub仓库或拖拽上传文件夹
5. 自动部署，获得 `.vercel.app` 域名

#### 方案3：Netlify（免费）

1. 访问 [netlify.com](https://netlify.com)
2. 拖拽项目文件夹到部署区域
3. 自动获得 `.netlify.app` 域名

#### 方案4：国内服务器/对象存储

- 阿里云OSS + CDN
- 腾讯云COS + CDN
- 七牛云存储

上传所有文件到存储桶，开启静态网站托管即可。

## 使用说明

1. **选择年级**：点击顶部年级按钮（3-6年级）
2. **选择册别**：点击"上册"/"下册"切换
3. **学习模式**：
   - 📚 单词学习：逐个学习单词，支持朗读和例句
   - 📖 课文朗读：阅读完整课文
   - 📝 单词测试：随机测试巩固记忆
4. **单元选择**：在单词学习模式下可选择具体单元或全部单元

## 注意事项

- 首次使用请允许浏览器使用麦克风（用于语音功能）
- 建议使用Chrome或Edge浏览器获得最佳体验
- 语音功能需要网络连接
